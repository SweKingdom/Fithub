# User manual

## How to view the class schedule for the next two weeks

Use this page to see which classes a club offers in the next 14 days, how many places are left, and whether you have already booked.

1. Sign in to FitHub.
2. Open **Schedule** in the top menu. (Until the menu link is available, go to `/schedule`.)
3. In the **Club** selector, choose the club. The page opens with the club from the link if one is given, otherwise your home club, otherwise the first club by name.
4. Read the class cards. They are grouped by the club's local date, and each card shows the start time in the club's time zone.
5. To check another club, change **Club**. The list reloads and the address in the browser changes to the new club.

What you see on a class card:

| Card shows | Meaning |
|---|---|
| **Booked** | You have a confirmed booking for this class. |
| **Payment pending** | Your booking is waiting for payment. |
| **Full – join waiting list** | No places are left. No Book button is shown. |
| **Cancelled** | The class is cancelled. No action is possible. |
| No badge | You have no booking for this class. Places left are shown. |

Tips:
- Only classes that have not started yet are listed, up to 14 days ahead.
- Places left can change while you look at the page. Reload the page to see the latest number.
- Other members' bookings are never shown.
- If the list does not load, select **Try again**.
- If the **Club** selector is disabled and shows "There are no clubs to show a schedule for yet.", no club is set up yet. Contact your club.
- If no classes appear, the message "No classes scheduled in the next two weeks." is shown.
